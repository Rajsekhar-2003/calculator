# 🧮 Calculator

A sleek, dark-mode calculator web app with a glassmorphism aesthetic. Built with **HTML**, **CSS**, and **JavaScript**.  
Live demo: [https://rajsekhar-2003.github.io/calculator/](https://rajsekhar-2003.github.io/calculator/)

---

## ✨ Features

- **Basic arithmetic**: addition, subtraction, multiplication, division
- **Clear** (`AC`) and **backspace** (`⌫`) functionality
- **Percentage** (`%`) and **sign toggle** (`±`)
- **Keyboard support** – type with your physical keyboard
- **Responsive** – works on desktop, tablet, and mobile
- **Dark glassmorphism UI** with smooth hover/click feedback
- **Error handling** for division by zero and invalid expressions

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5      | Structure |
| CSS3       | Styling, glassmorphism, animations |
| JavaScript | Logic, event handling, keyboard support |
| Font Awesome | Icons (optional enhancement) |
